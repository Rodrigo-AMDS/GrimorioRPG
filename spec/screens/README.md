# Specs de telas

Crie um arquivo por tela ou fluxo, com nome curto em kebab-case, e use `../templates/screen-spec.md`.

Exemplos: `campaign-archive.md`, `character-sheet.md`, `master-inventory.md`.

Toda task que alterar uma tela deve apontar para a spec correspondente e atualizá-la no mesmo commit. Se ainda não houver spec, crie-a na task antes de considerar a entrega pronta.
