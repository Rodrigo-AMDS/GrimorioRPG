# Specs globais

Documente aqui regras que atravessam mais de uma tela. Consulte `docs/PRODUCT_SPEC.md` antes de criar regras de produto e `docs/DATABASE_REVIEW.md` antes de definir contratos de dados.

- `security-and-data.md`: autenticação, autorização, isolamento por campanha, mídia e limites do cliente.
- `database.md`: schema, relações, índices, migrações e operações permitidas.

Mudanças globais atualizam a spec de sistema correspondente e criam uma task em `tasks/` mesmo quando nenhuma tela é alterada.
